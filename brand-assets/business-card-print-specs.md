# She's The Vibe Co — Business Card Print Specs
**Size:** 3.5" × 2" (1050 × 600 px @ 300 DPI) — US standard
**Files:** business-card-front.png, business-card-back.png

## FRONT (burgundy background)
| Element | Treatment |
|---|---|
| "She's The Vibe Co" script text | **GOLD FOIL** + light emboss (raised) |
| "PRACTICAL. PRETTY. YOU." tagline | **GOLD FOIL** (flat, no emboss) |
| Gold frame border (double rule) | **GOLD FOIL** (flat) |
| Corner sparkles + center sparkle cluster | **GOLD FOIL** (flat) |
| Flourish swirls | **GOLD FOIL** (flat) |
| "COACHING • PLANNERS • HANDMADE" | **GOLD FOIL** (flat) |
| Burgundy background | Flat CMYK print (rich black-burgundy) |
| "She's The Vibe Co" area | Consider **spot emboss** (blind/dry) for tactile raise |

**Recommended stock:** 16pt or 18pt matte with soft-touch laminate (foil pops on matte)

## BACK (cream background)
| Element | Treatment |
|---|---|
| Burgundy left accent bar | Flat print |
| "V / STV" brand mark circle | **GOLD FOIL** circle outline; flat burgundy fill |
| "Christina Wood" name | Flat burgundy print (or blind emboss for texture) |
| "Founder & CEO" | Flat gold print |
| Contact lines (email/phone/web) | Flat burgundy print |
| Gold bullet sparkles | Flat gold print |
| Gold divider line | Flat gold print |
| QR code | Flat burgundy print |
| "Practical. Pretty. You." | Flat gold italic print |

**Recommended stock:** Same 16pt/18pt matte to match front

## Printer notes
- Provide both PNGs at 300 DPI with 0.125" bleed if printer requires (add in prepress)
- Foil: metallic champagne gold to match #C9A96E as closely as possible
- Emboss: front title only (registered emboss aligned to foil)
- Ask printer for a foil proof before full run
